Kolekcija Dodaj album XML Schema

XML Schema (XSD)

Kompletna schema koja definira i validira strukturu music_db.xml

Struktura elemenata
<library>
Korijen dokumenta. Sadrži 0..∞ albuma (minOccurs="0" maxOccurs="unbounded")
<album id="...">
Kompleksni tip albumType. Obavezni atribut id (use="required"). Sadrži sekvencijalne elemente (redosljed bitan).
<rating> — ratingType
Vlastiti xs:simpleType koji ograničava integer:
minInclusive=1, maxInclusive=5
<tracks> / <track num="...">
tracksType zahtijeva minOccurs="1" — album mora imati barem jednu pjesmu. Atribut num je xs:positiveInteger.
Tipovi podataka (xs:)
Element XSD tip
title xs:string
artist xs:string
year xs:gYear
genre xs:string
rating ratingType (custom)
track/@num xs:positiveInteger
track/duration xs:string
